## 问题1：你的产品最大的亮点是什么？是如何服务于B站UP主、用户和社区呢？

**最大亮点：不是提词器--平时让你自然说，只在卡壳瞬间递一个钩子解冻。**

提词器需要提前写稿、逼你照本宣科，无法真实表达；Q 平时完全不插手，让你自然说，只有在你冻住的瞬间递一个 ≤5 字的钩子（开头三字 / 框架 / 衔接 / 节奏），帮你重新开口。**垫不替--不替你说，垫一下让你自己接。** 对"自然表达更好但会卡壳"的 UP主，这是唯一不破坏风格的解法。

**五大能力**（全部在你真实讲话时实时发生）：

- 📊 **实时效果监测**：实时打三维分（流畅度 / 逻辑度 / 接收度），数口头禅，标紧张时刻，讲完出复盘报告
- 🪝 **卡壳瞬间递钩**：冻住时递 ≤5 字钩子解冻，倒计时学你的节奏，快的不拖、慢的不催
- 🔗 **表达能力上链**：改进铸成 Injective 链上凭证，不可伪造、不可转移
- 🌱 **接话递好建议**：接住钩子后给一条具体改进建议（如"结论先行""少用然后"），入库积累
- 🛡️ **双向开口减压**：语言端兜底不翻车 + 视觉端 PICO 遮脸不紧张（镜头前不怯场）

**服务 B站：**

- **UP主**：帮入门 UP主 跨过"镜头前卡壳 / 紧张"的坎，敢尝试 vlog / 口播 / 科普讲解 / 直播等更多形式；录完看复盘报告，持续进步
- **用户**：看到的是自然、自信的内容，而非念稿的生硬
- **社区**：降低表达门槛 -> 更多普通人成为 UP主 -> 内容更多元、社区更活

> 契合赛道评分：创新性 40%（"非提词器、只在冻住时出手"是表达工具的新品类）+ 可落地性 20%（讯飞 STT + 阶跃星辰 + PICO，技术栈现成）+ 完成度 20%（卡壳递钩 + 效果监测 72h 可跑通）+ 扩展性 20%（录制 -> 直播 -> 线下演讲 / 答辩）

## 问题2：如果你参与了直播，告诉我们你做了怎样的直播整活策划？

**直播整活：「AI 教练实时救场」--让观众亲眼看见一个 UP主 被实时解冻**

直播流程：

1. 我在直播里真讲一段（分享话题 / 复盘项目）
2. 大屏实时展示三路信号：语音转写 + 卡壳检测（冻住瞬间高亮红色）+ Q 递的钩子
3. 卡壳瞬间：大屏看到"冻住"信号飙红 -> Q 递一个开头钩子 -> 我接住、重新开口
4. 对比演示：同一段话"无 Q（冷场尴尬） vs 有 Q（递钩解冻）"的剪辑对比

**核心整活点**：让观众"亲眼看见"一个 UP主 的卡壳被实时解冻--这是直播才有的实时张力，也是 Q 最打人的 wow moment。

**素材**：用我举办开幕式的讲话录像做素材--找出卡壳 / 破绽瞬间，剪辑成"无 Q（冷场） vs 有 Q（递钩解冻）"对比。

**整活升级：采访 26 位参赛选手**

- 现场采访 26 位选手的"表达 / 沟通卡壳瞬间"（你录视频 / 直播时最卡的是哪一下？），剪成一支 2 分钟短视频
- 这既是 B站 直播整活的核心素材，也是一支独立可发的 B站 视频（"AdventureX 26 个人的表达破绽"）

## 现场 Demo：两块屏幕

- **屏 1（视频）**：开幕式讲话破绽剪辑（原版冷场 vs Q 解冻版对比）/ 或 2min 采访片
- **屏 2（现场 PICO + 数据）**：现场佩戴 PICO 头显实时画面 + 双路信号（语音转写 + 卡壳检测高亮）+ 递钩瞬间 + 效果分 + 口头禅计数

屏 1 给"故事 / 共鸣"（真实破绽被救），屏 2 给"技术 / 实时"（现场可见解冻发生）。两屏互补：一个打动人，一个证明能做。
