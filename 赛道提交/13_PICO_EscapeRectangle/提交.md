## 1.2 项目概述

**Q（Cue）× PICO** 是一款为 PICO OS 6 打造的**空间表达辅助+成长系统**。发言者戴上 PICO 头显真实讲话时，系统在空间里同时做五件事：实时监测表达效果、卡壳时递钩兜底、把表达能力铸成链上凭证、接话后递素养建议、并用 MR 遮住听众人脸表情来减压。

**它如何运作**：PICO 是核心设备，承担全部感知与显示--
- **麦克风** -> 讯飞 STT 实时转写 -> 阶跃星辰评分/递钩/素养引导；
- **摄像头** -> 读心镜解析听众微表情与潜台词 + SecureMR Pipeline 做端侧人脸检测（NPU 加速）做遮脸减压；
- **空间显示** -> 空间 HUD 递分数 / 钩子 / 建议 / 3D 凭证卡片；
- **空间锚定 + MR 透视** -> 在听众人脸位置叠加化身（冬瓜）遮挡真实表情。
指环（IMU 微颤 + 按钮 + 心率[手动输入]）为身体接口，与 PICO 协同感知卡壳。

**它为什么有吸引力**：今天所有表达辅助工具都困在**平面矩形**里--分数挤在手机小屏、提词器需要提前写稿逼你照本宣科无法真实表达、AI 对话框成不了真实场景的助手。Q 借 PICO 的空间计算把这五件事全部**逃出矩形、长进空间**：分数/钩子/凭证在 3D 空间悬浮，人脸遮挡扩展到整个真实环境，读心镜在真实空间里读真实听众。表达辅助第一次从"盯着一块屏"变成"置身一个空间"。这正是"Escape the Rectangle"的字面与精神双重实现。

> **现实与愿景**：PICO 头显目前仍过于厚重，无法在真实表达场景中长时间佩戴。但我们相信，在未来，XR 设备将真正走进人们的生活--变得轻薄到可以自然戴着讲话。Q 的空间表达辅助系统正是为那个未来准备的；当下以真机/模拟器演示验证可行性，等待硬件成熟即无缝迁入日常。

## 1.3 问题陈述

**目标用户**：需要当众讲话但容易卡壳/紧张的人--创业者（路演/答辩）、学生（课堂展示）、内容创作者（录视频/直播）、销售。以及要解析对手、临场供给弹药的高利害沟通者。

**当前痛点/差距**（五个痛点，工具全没解决）：
1. **效果无评判** -- 讲完不知道讲得好不好，全凭感觉；
2. **过程无兜底** -- 卡壳冻住没人递话，越慌越断；
3. **能力无证明** -- "我沟通能力强"完全不可证，简历放不上去；
4. **素材难培养** -- 没有人在你讲话后给具体可改的建议，更不会回检你改了没；
5. **开口太紧张** -- 看到听众皱眉走神就断线；提词器需要提前写稿、逼你念稿，无法真实表达，更管不了"看到表情就慌"。

现有工具里，提词器需要提前写稿、逼你照本宣科无法真实表达，录音回放只能事后复盘，手机 AI 对话框困在屏幕里--全都无法在真实讲话场景中实时、在场地辅助。

**为什么空间计算是实现这一目标的正确媒介**：表达发生在真实三维空间，辅助必须跟着进入空间。PICO OS 6 的麦克风+摄像头+空间显示+MR 透视+空间锚定，让评判、兜底、证明、培养、减压全部在现场实时发生，而非事后盯着一块屏复盘。只有空间计算能同时"看见听众、读出情绪、遮住刺眼的表情、在空中递钩和凭证"。

## 2.3 核心功能（五大亮点，全部跑在 PICO 上）

1. **📊 实时效果监测**：PICO 麦克风 -> 讯飞 STT 实时转写 -> 阶跃星辰打三维分（流畅度/逻辑度/接收度），数口头禅、标紧张时刻，讲完出复盘报告。PICO 摄像头 -> 读心镜解析听众/对手微表情与潜台词，临场喂反击角度和数据金句。空间 HUD 实时显示分数与信号。
2. **🪝 卡壳瞬间递钩**：综合 PICO 麦克风（停顿+填充词）+ 指环（IMU 微颤+心率）判断卡壳 -> PICO 空间显示递 ≤5 字钩子（开头三字/框架/过渡/节奏），倒计时学你的节奏，快的不拖、慢的不催。**垫不替**--不替你说，垫一下让你自己接。
3. **🔗 表达能力上链**：把表达能力铸成 Injective 链上 soulbound 凭证，不可伪造、不可转移。钱包登录 -> 数据采集 -> 评分画像 -> 里程碑触发 -> CosmWasm 铸造 -> **PICO 空间显示 3D 凭证卡片**。讲完一段话，能力有据可查、简历能放、企业能验。
4. **🌱 接话递好建议**：每次接住钩子重新开口后，给一条具体可执行建议（如"结论先行""少用然后""举个例子"），PICO 空间显示递出；建议入库积累，复盘可见，未来自动回检是否做到，形成"建议->执行->验证"成长闭环。
5. **🛡️ 双向开口减压**：**语言端**--卡壳有钩兜底不翻车、口头禅超频提醒、心率飙升标记紧张；**视觉端**--PICO 摄像头 + SecureMR Pipeline 实时检测听众人脸（NPU 加速），在人脸位置叠加化身（冬瓜）遮住真实表情。发言者看到的不是皱眉走神，而是中性友好面孔，降低被审视感，更敢开口。

> **"Escape the Rectangle"贯穿五亮点**：①分数从手机小屏逃到空间 HUD；②钩子从字幕条逃到空中悬浮；③凭证从纸质/网页逃到 3D 空间卡片；④建议从对话框逃到空间递送；⑤遮脸减压从小 HUD 矩形逃到整个真实空间 MR。

## 竞争与策略

- 预估参赛 10–18，获奖率中高：PICO OS 6 / 空间开发有门槛，硬件门槛 = 护城河。
- 我们的差异：多数空间应用是从零造一个空间玩法；我们是把"当众表达"这个真实痛点，用 PICO 的全感知（麦克风+摄像头）+ 全显示（空间渲染+MR）做成一个**五合一的在场辅助系统**，且有主系统技术纵深背书（卡壳检测融合麦克风停顿+填充词+指环微颤+心率多信号），不是单点 demo。

## 硬件依赖说明

- **PICO 头显（核心设备）**：麦克风（STT 感知）+ 摄像头（读心镜读听众 + 人脸遮挡）+ 空间显示（分数/钩子/建议/3D 凭证）+ MR 透视 + 空间锚定（化身定位）。
- 技术栈 Unity Integration SDK 3.4.0 + SecureMR，运行于组织方借到的 PICO 4/4U 真机（真摄像头 + 真 NPU）；SecureMR = SpatialML 的 Unity 等价物（Session->Pipeline->Tensor->Operator + 相机 + NPU）。
- **指环（Zilo）**：IMU 微颤检测 + 按钮确认/消除 + 震动提醒 + 心率[手动输入]，为身体接口，与 PICO 协同感知卡壳。
- 若真机不可用，退化到模拟器演示（组织方已明确"模拟器不影响评审"），人脸遮挡以录屏素材兜底。
