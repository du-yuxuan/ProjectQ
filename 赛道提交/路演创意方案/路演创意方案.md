# Q 现场/开幕创意方案（不写 pitch）

> 身份：黑客松联合发起人，做开幕讲话
> 核心：用"真实开幕讲话破绽被救场"开场，用"两屏实时"证明能做，用"For XXX"覆盖每个赛道评委，用手机APP让参观者也参与。
> 说明：这不是 pitch 脚本，是现场/开幕的创意执行方案。

---

## 一、现场主线（一句话）

> "我是这场黑客松的联合发起人，我要做开幕讲话。而我会卡壳。我把我讲话的破绽剪出来，用 Q 把每个破绽解冻、评判、培养。今天我还采访了 26 位选手的破绽--这是 26 个人都有的瞬间。"

主线 = 真实破绽（共鸣）-> 现场评判+兜底（技术）-> 26 个人的破绽（普适）-> 每个赛道的案例（覆盖）-> 手机APP（参与）。

---

## 二、四段式内容

### 段1：采访 26 位参赛选手（2min 短片）
- 采访 26 位选手"你在录视频/路演/答辩时，最卡壳的是哪一下？"，剪成 2 分钟短片「26 个人的表达破绽」。
- 证明这不是我的个人问题，是人人都会的瞬间。
- 既开场共鸣，也是 B站 内容/直播整活素材。

### 段2：For XXX -- 每个赛道一个案例
Q 跨 6 赛道，每家提供方一个 10-15 秒定向案例：

| For XXX | 案例核心 |
|---------|---------|
| For Zilo | 指环感知卡壳微颤/停顿 |
| For Injective | 能力铸成链上凭证 |
| For B站 | 开幕讲话/真实表达场景解冻 |
| For superun | 从"离问题最近"的 Context 建出来 |
| For 智能少年 | 只有我这个要上台的人能做 |
| For Amazon | 用 Kiro 快速搭、0.x 秒救场 |

### 段3：现场两屏 Demo
| 屏幕 | 内容 | 作用 |
|------|------|------|
| 屏1（视频） | 开幕讲话破绽剪辑：原版（冷场/尴尬）vs Q 版（兜底解冻+效果评判） | 打动人 |
| 屏2（现场） | 现场 Rokid 眼镜实时画面 + 双路信号（转写+卡壳高亮）+ 递钩 + 效果分 + 能力画像 + 铸证 + 素养小引导 | 证明能做 |

### 段4：手机 APP（现场参观者参与）
- 参观者扫码用手机 APP：录一段，得表达效果评判 + 接话素养小引导
- 让全场不只是看，还能"被评判、被培养"

---

## 三、现场流程（开幕/路演，5-8 分钟）

1. 开场（30s）："我是发起人，我会卡壳" + 放 2min 采访短片
2. 问题（30s）：短片钩子 -> 提词器毁自然、卡壳没人解决、效果无评判/能力无证明
3. 方案（1min）：Q 四模块（评判/兜底/证明/培养）
4. For XXX（1min）：六赛道案例串讲，覆盖全场评委
5. 两屏 demo（2min）：屏1 破绽剪辑 + 屏2 实时评判+兜底+铸证
6. 手机APP（30s）：参观者扫码参与
7. 收尾（30s）："26 个人都有破绽，Q 让每个破绽被评判、被兜底、被培养、被证明"（Reverse 闭环）

## 五、为什么这个现场能打

1. 真实素材：开幕讲话是你自己的真实破绽（甚至可现场 live demo）。
2. 全场覆盖：For XXX 让每个赛道评委觉得"跟我有关"。
3. 两屏互补：屏1 打动，屏2 证明。
4. 参观者参与：手机APP 让全场不只是看。
5. 普适共鸣：26 个人的破绽，把"我的问题"放大成"人人的问题"。
6. Reverse 闭环：开场"会卡壳"->结尾"每个破绽被评判/兜底/培养/证明"，反转贯穿。

## 六、与各赛道呼应
- B站：2min 采访片 = B站 内容/直播整活
- superun：现场讲的就是"我离问题最近"的故事
- Reverse：开场破绽->结尾被救场，本身是反转
- 其余赛道：For XXX 段覆盖
