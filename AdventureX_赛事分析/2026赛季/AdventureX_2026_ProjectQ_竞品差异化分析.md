# ProjectQ 竞品差异化分析

> 项目：Q（Cue）
> 数据来源：2025 Gallery 全量数据（222 项目 / 119 获奖）+ 2026 竞争预估 + Q 项目文档
> 分析日期：2026-07-26
> 注意：2026 Gallery 因网络限制未能实时抓取，以下基于 2025 规律 + 2026 赛道预估推断，拿到实际 Gallery 数据后可进一步校准

---

## 一、Q 与其他项目最不一样的亮点

### 1. 全场唯一把"表达能力"铸成链上凭证

2025 Gallery 222 个项目里，区块链项目几乎全是 DeFi / NFT / DAO / 交易类。**没有任何项目把"软技能"（沟通力 / 表达力）铸成不可转移的链上凭证。** Q 的 soulbound 凭证让"我沟通能力强"这个平时完全不可证的软技能，变成可携带、防篡改的链上证明--这是 Injective 链上全新的用例类别。

### 2. "不是提词器"--表达工具的新品类

2025 的 AI 项目几乎全是**内容生成**（生成视频 / 文字 / 图片 / 代码）。Q 不生成内容，而是在你**真实讲话时**实时辅助--卡壳递钩、实时打分、遮脸减压。提词器需要提前写稿、逼你念稿，无法真实表达；Q 平时让你自然说，只在冻住瞬间垫一下。这是一个没人做的品类。

### 3. 硬件 + AI + 链上三栈融合

2025 多奖项目（≥3 奖，仅 10/222）的共同特征是跨领域融合。Q 同时用：
- **PICO 头显**（空间感知 + MR 透视 + 空间显示）
- **Zilo 指环**（IMU 微颤 + 按钮身体接口）
- **讯飞 + 阶跃星辰**（STT + LLM 实时评分/递钩）
- **Injective**（CosmWasm soulbound 凭证）

2025 高获奖率技术栈里，Web3.js 80%、GPT 81%、Multi-Agent 71%--Q 同时命中多个高获奖率栈。

### 4. 发起人亲历的真实痛点

2025 评审规律核心：**"人的视角是唯一评判锚点"**。多数项目的痛点是"想出来的"，Q 的痛点是发起人自己的--要做开幕讲话、却会卡壳。这个真实性在 2025 获奖项目里是最稀缺的。

### 5. 广撒网 + 六赛道同打

2025 数据证明：参加 5 个赞助赛道的项目获奖率 62%（人均 1.1 奖），仅参加 1-2 个的只有 33-44%。Q 同时打 6 个赞助赛道 + 1 个主题赛道，是全场覆盖最广的项目之一。

## 二、同赛道定向优化后的差异化亮点

### 01 Injective（预计 60-90 参赛，~8% 获奖）

**竞品画像**：大多做 DeFi 交易 / NFT 市场 / DAO 工具 / 代币经济。

**Q 的差异化**：全场唯一把**软技能**上链。别人把金融资产上链，Q 把"沟通能力"这种平时完全不可证的软技能铸成 soulbound 凭证。

**定向优化建议**：
- 钩子：**"别人上链的是钱，我们上链的是能力"**
- 强调三环缺一不可：硬件测了才可信 → 链上存证才可携带 → 不可转移才不可伪造
- 展示完整流程：钱包登录 → 采集 → 评分 → 里程碑 → CosmWasm 铸造 → PICO 3D 卡片
- 诚实说明 SDK 降级（合约编译通过 224KB，SDK 未完全集成），但路径清晰可审

### 13 PICO（预计 10-18 参赛，中高获奖率）

**竞品画像**：大多做空间游戏 / 3D 可视化 / MR 娱乐体验。

**Q 的差异化**：不做空间小游戏，做**真实表达辅助**。PICO 不用来玩，用来在你讲话时遮住听众表情减压 + 空间递钩 + 空间显示分数。

**定向优化建议**：
- 钩子：**"别人用空间做玩具，我们用空间解真实焦虑"**
- "Escape the Rectangle"贯穿五大亮点：分数/钩子/凭证/建议/遮脸全部从平面矩形逃进空间
- 强调硬件门槛 = 护城河（需 PICO OS 6 / 空间开发）
- 加 PICO 太厚重的前瞻声明：当下演示验证，等 XR 轻薄化无缝迁入

### 05 智能少年（预计 15-25 参赛，~5% 获奖）

**竞品画像**：大多做 AI 教育工具 / 学习辅助 / 儿童产品。

**Q 的差异化**：不做教育工具，做**只有我能做的解冻器**。它长在发起人的三圈交集上--不是想出来的痛点，是亲历的。

**定向优化建议**：
- 钩子：**"不做第一，做唯一--这是只有我会卡壳的人才会做的东西"**
- 强调真实性 40%：开幕讲话是真素材，不是模拟
- ③为 10 后而造：遮脸减压让孩子不怕看同学表情 + 卡壳递钩让孩子敢开口 + PICO 太厚重的前瞻愿景
- 不要把自己定位成"教育产品"，而是"个人表达解冻器"

### 08 B站（预计 20-35 参赛）

**竞品画像**：大多做 AI 内容生成（视频/弹幕/AI UP主）/ 社区互动工具。

**Q 的差异化**：不做内容生成，做**创作者本人的表达解冻**。别人帮 UP主 生成内容，Q 帮 UP主 在镜头前不卡壳、不紧张。

**定向优化建议**：
- 钩子：**"别人帮 UP主 做内容，我们帮 UP主 敢开口"**
- 提词器对比要狠：提前写稿 / 逼你念稿 / 无法真实表达 vs Q 让你自然说 + 只在卡壳时垫一下
- 直播整活：大屏实时展示卡壳检测 + 递钩解冻，让观众亲眼看见"被解冻"的瞬间

### 17 superun（预计 15-25 参赛）

**竞品画像**：大多用 superun 做完整应用。

**Q 的差异化**：只用 superun 做了 Landing Page，但**离问题最近**。赛道核心是"不比代码，比谁离问题最近"，Q 的发起人亲历卡壳、调研透了表达问题。

**定向优化建议**：
- 钩子：**"别人比谁代码多，我们比谁离问题近"**
- 不要掩饰 superun 只做了 Landing Page--诚实反而是"离问题最近"的最好证明
- 三问答案紧扣"Context"：你的经历 = 最宝贵的 AI Context

### 23 Zilo 弦指（预计 8-15 参赛，赛道空、获奖率高）

**竞品画像**：大多把指环当**遥控器 / 手势输入设备**控制其他东西。

**Q 的差异化**：把指环重新定义为**身体接口**--不控制外部设备，而是感知你自己的紧张度（IMU 微颤 + 心率）。

**定向优化建议**：
- 钩子：**"别人用指环控制世界，我们用指环感知自己"**
- 强调"不做遥控器，做身体接口"的重新定义
- 微颤检测 → 卡壳前感知 → 预测式兜底（未来）
- 赛道空 + 硬件门槛 = 最高性价比赛道，重点投入

## 三、怎样介绍这些亮点会更好

### 策略 1：一句话钩子先行，再展开

每个赛道用**一句话差异化钩子**开场，让评委 3 秒内 get 到"这个不一样"：

- Injective：**"别人上链的是钱，我们上链的是能力"**
- PICO：**"别人用空间做玩具，我们用空间解真实焦虑"**
- 智能少年：**"只有我会卡壳的人，才会做这个东西"**
- B站：**"别人帮 UP主 做内容，我们帮 UP主 敢开口"**
- superun：**"别人比谁代码多，我们比谁离问题近"**
- Zilo：**"别人用指环控制世界，我们用指环感知自己"**

### 策略 2：提词器对比要狠

每次介绍都先打提词器：**"提词器需要提前写稿、逼你照本宣科，无法真实表达；Q 平时让你自然说，只在卡壳瞬间垫一下让你自己接。"** 这是全场没人能复制的对比--因为只有 Q 做的是"不替你说"的辅助。

### 策略 3：用"全场唯一"做锚

2025 评审规律：**"人的视角是唯一评判锚点"**。Q 有多个"全场唯一"：
- 全场唯一把表达能力上链
- 全场唯一做"不替你说只垫一下"的表达辅助
- 全场唯一用 PICO MR 遮脸减压
- 发起人亲历的痛点（不是想出来的）

介绍时反复锚定"全场唯一"，让评委记住"这个项目别人做不了"。

### 策略 4：真实性 > 完成度

2025 规律：哲学深度 > 技术完成度（部分赛道）。Q 的 SDK 未完全集成、PICO 太厚重戴不了--**不要藏，反而要讲**：

- "合约编译通过了 224KB，但 SDK 还没跑通真实上链，我们降级了"→ 诚实 + 路径清晰 = 评委信任
- "PICO 太厚重戴不了，但我们相信未来 XR 会走进生活"→ 前瞻 + 愿景 = 加分
- "我只用 superun 做了 Landing Page"→ 但我离问题最近 = 扣题

### 策略 5：Demo 用真实素材，不用模拟

开幕讲话破绽剪辑是 Q 最强的武器。2025 获奖项目特征：**真实场景 > 模拟 demo**。用发起人自己的讲话录像做"无 Q vs 有 Q"对比，比任何模拟 demo 都有说服力。

### 策略 6：六赛道一句话统一定位

> **Q -- 卡壳时，递你一句 Cue。不是提词器，是真实表达场景里既辅助又成长：评判 / 兜底 / 证明 / 培养 / 减压。**

六赛道共用一个核心定位，但每赛道用不同的"一句话钩子"切入，让评委觉得"这个项目在这个赛道也是不一样的"。
