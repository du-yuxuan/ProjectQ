# Zilo Ring 滚动FAQ

## \<戒指的功能\>

Zilo Whisper 智能戒指内置六轴 IMU 传感器、麦克风和实体按钮，并提供 SDK，方便大家进行功能开发与拓展。

1. 传感器功能：戒指搭载六轴 IMU，其中包含加速度传感器。通过蓝牙连接后，可实时读取 IMU 原始数据。

2. 手势识别：戒指内置基础手势识别功能。大家也可以基于 IMU 原始数据，自行开发更多手势识别方案及其他交互逻辑。

3. 语音交互：戒指内置麦克风，支持语音交互及相关功能开发。

目前不支持的功能：心率监测、震动模块



## **\<如何连接戒指\>**

建议前往周边蓝牙设备较少的区域进行扫描，避免因设备过多影响识别。

可以通过以下任一方式扫描附近设备：

- 使用 SDK 中提供的 Demo 软件

- 使用蓝牙助手等工具

找到名称为“ring”的蓝牙设备后，后续使用可以用ring来筛选附近蓝牙设备。

确认设备后，可以通过以下方式与戒指进行交互：

- 调用我们提供的 SDK

- 根据通信协议中提供的 UUID 进行连接和数据交互

长按戒指按钮后，指示灯应保持常亮。如果指示灯没有亮起，戒指可能处于无电状态，请先充电（见\<充电说明\>），再尝试使用。



## **\<如何使用 Zilo Ring\>**

1. 长按至绿灯亮起：进入录音状态

2. 单击按钮：切换工作状态

3. 长按至红灯亮起：进入 IMU 数据采集状态

4. 使用内置手势识别时：进入 IMU 采集状态后，长按按钮完成手势动作并松开。如果识别成功，戒指会自动上报对应动作。

5. 获取 IMU 原始数据时：不需要一直长按按钮。只需确保戒指处于 IMU 采集状态，然后通过 SDK 或通信协议发送数据请求，戒指即可实时传输采集到的 IMU 原始数据。

6. 关于开关机：戒指暂时没有单独的开关机功能，正常情况下会持续进行蓝牙广播。
