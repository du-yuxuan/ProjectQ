# Q Ring Debug App - 技术说明

> 项目: 在 Rokid 眼镜(裸机)上运行的原生 Android 实验应用，连接 Zilo Whisper 指环并调试其全部功能，带 UI。
> 日期: 2026-07-23
> 目标设备: Rokid RG-glasses (Android 12, BLE on, 已开启 adb)
> 依据: `参考资料/ring_sound_SDK/{ring_sound.py, protocol.md, ring_sound_use.md, README.md}` + Rokid glass-docs 设计规范

## 一、技术架构

四层架构，自底向上:

```
┌─────────────────────────────────────────────┐
│ UI 层   MainActivity (ViewBinding, 眼镜友好布局)  │  按钮/日志/IMU实时显示
├─────────────────────────────────────────────┤
│ 命令层  RingCommander                           │  高层命令封装(系统/日志/校时/录音/IMU)
├─────────────────────────────────────────────┤
│ BLE 层  RingBleManager                           │  扫描NUS/连接/启用TX通知/写RX分片/包回调
├─────────────────────────────────────────────┤
│ 协议层  RingProtocol                             │  CRC16/包编解码/PacketStream重组/命令常量/解析
└─────────────────────────────────────────────┘
```

数据流: 指环 BLE 通知(TX 6E400003) -> RingBleManager.onCharacteristicChanged -> PacketStream.feed 重组 -> RingProtocol.decode -> onPacket 回调 -> MainActivity.handlePacket 按命令分发解析 -> UI 显示。

下行: UI 按钮 -> RingCommander -> RingProtocol.encode 编包 -> RingBleManager.send 分片写 RX(6E400002)。

## 二、方法

### 2.1 BLE 连接 (NUS 标准服务)
- 扫描: 按 NUS 服务 UUID(6E400001) 过滤，降级按设备名"ring"匹配。
- 连接: connectGatt(TRANSPORT_LE) -> discoverServices -> 取 NUS 服务/特性 -> 启用 TX 通知(writeDescriptor 2902)。
- 读写: TX(6E400003) notify 收数据; RX(6E400002) 写指令(分片，MTU≈20)。
- 依据: ring_sound SDK 用标准 NUS BLE，任何 BLE central 可连。Rokid 眼镜为 Android，原生支持 BLE central。

### 2.2 v4 协议实现
- 包头 11 字节(大端序): magic 0x3F | version u16(4) | command u16 | body_length u32 | body_crc u16。
- CRC16: 与 ring_sound.py `crc16_compute` 完全一致(初始 0xFFFF)。
- PacketStream: 累积 BLE 通知片段，按 magic 定位、按 body_length 取整包、CRC 校验、产出完整 Packet。
- encode/decode: 严格按 protocol.md 字段与字节序。

### 2.3 功能实现 (全部指环功能)
| 功能 | 命令 | 实现 |
|------|------|------|
| 系统信息 | 0x0101 | getSystemInfo -> 解析固件/时间/存储 |
| 日志存储 | 0x0301 | getLogStorage |
| 日志数据 | 0x0303 | readLogChunk(offset,length) |
| 校时 | 0x0401/0x0402 | 收请求解析T1，应答T1T2T3 |
| 录音数量 | 0x0501 | getAudioCount |
| 快速提取 | 0x0509 | startQuickExtract(index) |
| 录音帧 | 0x0505 | 实时显示 idx/off/size/end |
| 清空录音 | 0x050B | clearAudio (破坏性) |
| IMU开启 | 0x0601 | startSensor -> 解析采样率/量程 |
| IMU停止 | 0x0603 | stopSensor |
| IMU数据 | 0x0605 | 解析16字节样本(ts+6轴) 实时显示 |
| 双击事件 | 0x0701 | 实时日志 |
| 手势事件 | 0x0702 | 解析gesture_id |
| 按键双击 | 0x0703 | 实时日志 |
| 按键单击 | 0x0704 | 切模式事件 |

### 2.4 Rokid 设计规范遵循
- 眼镜显示特性: 480x640 小屏，采用单滚动布局、大字号(标题22sp/分区17sp/按钮16sp)、高对比(黑底/金标题/绿日志)。
- 简单触达: 按钮大(52dp高)，适配触控板 KEYCODE 操作。
- 说明: Rokid Glass UI SDK(com.rokid.glass:ui) 依赖 jcenter(已废弃)，故采用标准 AndroidX/Material 组件按规范自实现等效 UI(GlassAlignment 用于相机对齐场景，本调试 App 无相机对齐需求)。

## 三、代码结构

```
RingDebugApp/
├── settings.gradle / build.gradle / gradle.properties / gradle/wrapper/
├── app/
│   ├── build.gradle                      # AGP8.5.2 Kotlin1.9.24 compileSdk34 minSdk26 target31
│   └── src/main/
│       ├── AndroidManifest.xml           # BLE/Bluetooth权限 + uses-feature bluetooth_le
│       ├── java/com/unfreeze/ringdebug/
│       │   ├── MainActivity.kt            # UI + 包调度分发(157行)
│       │   ├── ble/RingBleManager.kt     # BLE扫描/连接/NUS读写/包回调(134行)
│       │   ├── cmd/RingCommander.kt      # 高层命令封装(53行)
│       │   └── proto/RingProtocol.kt      # v4协议:CRC16/包/流/解析(174行)
│       └── res/
│           ├── layout/activity_main.xml  # 眼镜友好布局
│           └── values/{styles,strings}.xml
└── 技术说明.md (本文件)
```

各文件职责:
- **RingProtocol.kt**: 纯协议层，无 Android 依赖(仅 java.nio)。CRC16/encode/decode/PacketStream/Reader/全部数据类与解析函数。
- **RingBleManager.kt**: Android BLE。BluetoothLeScanner 扫描、connectGatt、gattCallback(服务发现/TX通知/状态)、send 分片写 RX。
- **RingCommander.kt**: 把命令号包装成 getSystemInfo()/getAudioCount()/startQuickExtract()/startSensor() 等易用函数。
- **MainActivity.kt**: ViewBinding 绑定布局；设置 BLE 回调(onLog/onState/onScan/onPacket)；按钮触发命令；handlePacket 按 command 分发解析并更新 UI；运行时权限。

## 四、如何复现

### 4.1 环境
- Rokid 眼镜(RG-glasses, Android 12)，开启 adb(设置-开发者选项-USB调试)，USB 连电脑。
- 电脑: macOS，JDK17(`/opt/homebrew/opt/openjdk@17/libexec/openjdk.jdk/Contents/Home`)，Android SDK(build-tools 34, platform android-34)，Gradle 8.7(已下载 /tmp/gradle8)。
- Zilo Whisper 指环(长按亮灯进入广播)。

### 4.2 构建
```bash
cd RingDebugApp
export JAVA_HOME=/opt/homebrew/opt/openjdk@17/libexec/openjdk.jdk/Contents/Home
export ANDROID_HOME=$HOME/Android/sdk
/tmp/gradle8/gradle-8.7/bin/gradle assembleDebug
# 产出 app/build/outputs/apk/debug/app-debug.apk
```

### 4.3 安装与运行
```bash
ADB=$HOME/Android/sdk/platform-tools/adb
$ADB install -r app/build/outputs/apk/debug/app-debug.apk
# 授权(免手动点)
$ADB shell pm grant com.unfreeze.ringdebug android.permission.BLUETOOTH_SCAN
$ADB shell pm grant com.unfreeze.ringdebug android.permission.BLUETOOTH_CONNECT
$ADB shell pm grant com.unfreeze.ringdebug android.permission.ACCESS_FINE_LOCATION
# 启动
$ADB shell am start -n com.unfreeze.ringdebug/.MainActivity
```

### 4.4 调试指环
1. 长按指环按钮至指示灯亮(进入广播)。
2. App 点"扫描" -> 发现"ring [MAC]" -> 点"连接"。
3. 连接成功后按各分区按钮调试: 系统信息/校时/录音数量/快速提取/清空/开启IMU(实时6轴)/事件(双击/手势/按键)。
4. 底部日志区实时显示所有协议交互。

## 六、已知限制/后续
- 录音下载仅显示帧信息，未保存 .bin/.wav(可加 saveAudioBundle + ffmpeg 解码)。

- 无心率/震动(指环固件不支持，FAQ 已确认)。
