# Q 多端文档 · 手机端（iOS/Android App）

> 平台：iOS / Android（React Native 或 Flutter）
> 定位：评分平台 + 数据上链 + 参观者轻量入口。非实时，会话后复盘与社交层。

---

## 一、模块架构

```
MobileApp
├── report/         会话复盘
│   ├── ReportView          三维分曲线、卡壳点回放、钩子命中率
│   └── SegmentDetail       逐段转写 + 评分
├── profile/        跨会话能力画像
│   ├── RadarView           强项/弱项雷达
│   └── TrendView           进步曲线
├── chain/          链上凭证
│   ├── CredentialList      soulbound 凭证展示
│   └── WalletConnect       Injective 钱包/签名
├── lite/           参观者轻量版
│   └── QuickSession        仅手机麦 → 录一段 → 三维分 + 素养引导
└── net/ApiClient           REST 到后端
```

---

## 二、数据流

```
眼镜端会话结束 → 云端持久化 → 手机端拉取复盘
里程碑达标 → 云端触发 → Injective 铸造 → 手机端展示凭证
参观者扫码 → QuickSession → 手机麦 → 云端 StepAudio → 三维分 + 引导
```

---

## 三、两种使用模式

| 模式 | 硬件 | 场景 |
|------|------|------|
| 完整版 | 眼镜+指环+手机 | 主用户真实表达，事后复盘 |
| 轻量版 | 仅手机麦 | 现场参观者扫码，即录即评 |

---

## 四、链上交互

- 钱包连接 Injective 测试网/主网
- soulbound 凭证不可转移，绑定用户身份
- 铸证由云端后端发起（用户无需 gas），手机端只做展示 + 验证
- CredentialList 显示里程碑、铸造时间、交易哈希、链上可查链接

---

## 五、REST 接口（消费云端）

| 方法 | 路径 | 用途 |
|------|------|------|
| GET | /api/session/list | 会话历史 |
| GET | /api/session/:id | 会话详情（含段与钩子）|
| GET | /api/profile/:userId | 能力画像 |
| GET | /api/profile/:userId/trend | 进步曲线 |
| GET | /api/credential/list/:userId | 凭证列表 |
| POST | /api/feedback | 钩子评价 |
