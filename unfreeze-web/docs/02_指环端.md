# Q 多端文档 · 指环端（Zilo Whisper）

> 硬件：Zilo Whisper 指环（双麦 + IMU + 按钮）
> 对接：BLE NUS v4 协议（固件既有，不改固件）
> 定位：感知输入 + 控制器。

---

## 一、能力映射（基于 protocol.md）

```
双麦录音    → 0x0505 音频帧上报（Speex, 16kHz）
IMU 6轴     → 0x0601 开启 / 0x0605 批量数据（含采样率/量程）
HMM 手势    → 0x0702  rotate_back(1) / rotate_front(2) / wave(3)
普通双击    → 0x0701
按键单击    → 0x0704（切换录音↔手势模式）
按键双击    → 0x0703
校时        → 0x0401 指环请求 / 0x0402 眼镜应答
```

---

## 二、交互语义设计

| 指环动作 | 协议事件 | Q 语义 |
|---------|---------|--------------|
| 向后旋转 | 0x0702 gesture=1 | 换上一个钩子 |
| 向前旋转 | 0x0702 gesture=2 | 换下一个钩子 |
| 挥手 | 0x0702 gesture=3 | 划掉钩子/不需要 |
| 普通双击 | 0x0701 | 确认已恢复（记录 responseTimeMs）|
| 按键单击 | 0x0704 | 录音/手势模式切换 |
| 按键双击 | 0x0703 | 紧急暂停/取消会话 |

---

## 三、BLE 协议要点

- NUS 标准服务：Service 6E400001 / TX 6E400003(通知) / RX 6E400002(写)
- v4 协议头 11 字节大端：magic 0x3F | version(4) | command | body_length | body_crc
- CRC16 初始 0xFFFF，仅覆盖包体
- 通知可能拆包或粘包，需按 body_length 重组（PacketStream）
- 0x0605 每样本 16 字节：timestamp_ms(u32) + accel xyz(i16) + gyro xyz(i16)，每批最多 32 点

---

## 四、模式与约束

- 录音模式下本地 IMU 不采集；手势需先按键切到手势模式
- 0x0702 手势用设备内部 IMU，不需先发 0x0601；仅当需要实时 0x0605 原始数据时才 start_sensor_report
- BLE 断开设备自动关闭实时上报，眼镜端需重连恢复
- 固件不支持心率、振动（FAQ 已确认）；振动反馈待固件更新
- 时间戳对齐依赖校时握手，接话间隔精度取决于此

## 五、错误码

| 值 | 名称 | 说明 |
|---|------|------|
| 0 | SUCCESS | 成功 |
| 2 | DEVICE_BUSY | 设备忙碌（如录音模式下开 IMU）|
| 3 | FILE_NOT_EXIST | 文件不存在 |
| 6 | TIMEOUT | 操作超时 |
| 7 | PARAM_INVALID | 参数异常 |
| 8 | COMMUNICATION | 通信异常 |
