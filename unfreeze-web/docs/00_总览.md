## 一、端划分

```
        ┌──────────── 云端后端 ────────────┐
        │  StepAudio 中转 · 编排 · 持久化    │
        │  Injective 铸证 · 跨会话记忆       │
        └───────┬──────────────┬───────────┘
         WSS    │              │  HTTPS
        ┌───────▼──────┐   ┌───▼──────────┐
        │  眼镜端        │   │  手机端        │
        │ Rokid Android │   │ iOS/Android  │
        │ 核心计算+HUD   │   │ 评分平台+链上  │
        └───────┬──────┘   └──────────────┘
          BLE   │
        ┌───────▼──────┐
        │  指环端        │
        │ Zilo Whisper  │
        │ 感知+控制      │
        └──────────────┘
```

---

## 二、各端职责

| 端 | 硬件 | 语言/框架 | 核心职责 |
|----|------|----------|---------|
| 眼镜端 | Rokid RG-glasses (Android 12) | Kotlin + AndroidX | 主计算、HUD、摄像头、BLE Central |
| 指环端 | Zilo Whisper | 固件既有 + BLE NUS v4 协议 | 双麦、IMU 手势、按钮 |
| 手机端 | iOS / Android | React Native / Flutter | 复盘、画像、链上凭证、参观者入口 |
| 云端后端 | 服务器 | Node.js + Express + ws | StepAudio 中转、编排、持久化、铸证 |

---

## 三、端间协议汇总

| 链路 | 协议 | 内容 |
|------|------|------|
| 指环 ↔ 眼镜 | BLE NUS v4 | 音频帧/IMU/手势/按钮/校时 |
| 眼镜 ↔ 云端 | WSS | 音频上行、评分/钩子下行 |
| 手机 ↔ 云端 | HTTPS REST | 复盘/画像/凭证拉取 |
| 云端 ↔ StepAudio | WSS | 音频中转、JSON 响应 |
| 云端 ↔ Injective | gRPC/RPC | soulbound 铸证 |
