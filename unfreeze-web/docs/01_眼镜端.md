# Q 多端文档 · 眼镜端（Rokid Android）

> 硬件：Rokid RG-glasses (Android 12, BLE Central, 摄像头, HUD)
> 语言：Kotlin + AndroidX / Material
> 定位：核心计算中枢 + 唯一实时显示面，是整个系统的大脑。

---

## 一、模块架构

```
GlassApp (Kotlin)
├── ble/            BLE Central，连接指环
│   ├── RingBleManager      NUS 扫描/连接/通知（复用 RingDebugApp）
│   └── RingProtocol        v4 协议 CRC16/编解码
├── audio/          指环双麦音频流处理
│   ├── AudioStreamer       Speex 解码 → PCM → WSS 上行
│   └── TtsPlayer           钩子语音播报（骨传导/耳机）
├── vision/         摄像头听众感知
│   └── AudienceClassifier  CameraX 抽帧 → TFLite 专注/走神二分类
├── net/
│   └── SessionSocket       WSS 到后端，音频上行 + 评分/钩子下行
└── hud/            显示层（480×640 单屏）
    ├── ScoreHud            三维效果分实时
    ├── HookHud             钩子文字 + 倒计时
    └── ProfileHud          能力画像浮层
```

---

## 二、数据流

```
指环 BLE → RingBleManager → { 音频帧, IMU, 手势, 按钮 }
   ├─ 音频 → AudioStreamer → WSS → 云端 StepAudio
   ├─ 手势/按钮 → 本地映射 → HUD 交互（切钩子/确认/划掉）
摄像头 → AudienceClassifier → 接收度信号 → 与云端评分融合
云端 WSS → { score, hook, recovery } → HUD 渲染 + TtsPlayer
```

---

## 三、HUD 显示规范（Rokid）

- 分辨率 480×640，单滚动布局
- 高对比：黑底 / 金标题(22sp) / 绿日志(16sp) / 分区(17sp)
- 大按钮（52dp），适配触控板 KEYCODE
- ScoreHud：流畅度/逻辑度/接收度三维圆环，实时刷新
- HookHud：≤5 字钩子 + 倒计时环，倒计时时长来自云端 EMA 基准
- ProfileHud：会话末或手势唤出，显示能力画像

---

## 四、关键设计

- 摄像头二分类端侧跑 TFLite，不上传画面（隐私 + 延迟）
- BLE 层直接复用已验证的 RingDebugApp 协议实现（v4 CRC16）
- 音频上行走 WSS 到后端中转，眼镜端不直连 StepAudio（保护 Key、可拦截）
- 校时：眼镜端应答指环 0x0401 请求，保证接话间隔时间戳对齐
- 音频链路必须在会话期间保持 BLE 连接，断开则自动关闭指环实时上报
