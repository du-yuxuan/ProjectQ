## 〇、定位重述（核心变化）

- **不是表达练习 APP**：不让你专门去练，而是在你**真实讲话**时既兜底又培养。
- **既是辅助也是成长**：现场兜底（救场）+ 每次接话渐进培养素养（成长）。
- **手机 APP 版**：现场参观者可用，体验表达评判与培养。
- **四模块对应三个痛点 + 培养素养**：

| 痛点 | 模块 |
|------|------|
| ①表达效果无评判（难知好坏） | 模块1：表达效果评判 |
| ②表达过程无兜底（卡壳/衔接不自然） | 模块2：表达过程兜底 |
| ③表达能力无证明 | 模块3：表达能力评判 |
| ④表达素材难培养 | 模块4：表达素养培养 |

## 模块1：表达效果评判（对应"表达效果无评判"）

### 功能
实时评判你的表达效果好不好，给你一个客观的"好坏"反馈（不再凭感觉）。

### 检测信号
| 信号 | 来源 | 含义 |
|------|------|------|
| 语速/填充词/清晰度 | 讯飞韵律+STT | 流畅度 |
| 语义连贯性/结构 | 阶跃星辰分析转写 | 逻辑度 |
| 听众反应（专注/走神） | Rokid 摄像头 | 接收度 |

### 输出
- **实时**：表达效果分（流畅/逻辑/接收 三维）
- **事后**：复盘报告（哪好哪差、哪段听众掉线）

### 实现
讯飞 STT+韵律 + 阶跃星辰连贯性评分 + Rokid 听众检测 -> Dify 聚合打分。
**72h**：✅ 中（评分聚合可做；听众检测降二分类）。

---

## 模块2：表达过程兜底（对应"表达过程无兜底"）

### 功能
新手卡壳/衔接不自然时，实时兜底递钩救场。（吸收原四个"解冻"为子功能）

### 子功能（原四解冻）
| 子功能 | 触发 | 递什么 |
|--------|------|--------|
| 开口兜底 | 长停顿+填充词+IMU冻结分 | 开头三字 |
| 思路兜底 | 连贯性下降/漂移（或长按） | PREP/SCQA 框架 |
| 衔接兜底 | 句中断裂/被打断 | 过渡钩子 |
| 节奏兜底 | 语速偏离/听众走神 | 节奏/重述提示 |

### 约束
**垫不替**：只递节点（开头三字/框架骨架/过渡钩/指令），不给整句。

### 实现
讯飞 STT（停顿/打断/填充词）+ 阶跃星辰（生成钩子）+ IMU（冻结）+ 摄像头（听众）。
**72h**：开口兜底+衔接兜底必跑通（信号现成）；思路/节奏兜底可降级。

---

## 模块3：表达能力评判（对应"表达能力无证明"）

### 功能
跨多次会话积累评判数据，给出你的"表达能力"画像，并铸成链上可证凭证。

### 机制
- 模块1的"效果分"跨会话积累 -> 表达能力画像（强项/弱项/进步曲线）
- 达里程碑（某维度提升/卡壳率↓）-> 铸 Injective soulbound 凭证

### 输出
- 表达能力评估（多维度 + 进步趋势）
- Injective 链上凭证（可携带、防篡改、无中心发行方）

### 实现
Dify 跨会话记忆 + 卡点图谱/能力画像存储 + Injective 铸证合约。
**72h**：⚠️ 中（画像积累需多次会话；demo 可用预录事件序列驱动）。

---

## 模块4：表达素养培养（对应"表达素材难培养"）

### 功能
不让你专门练，而是在你**每次接话**时，系统给一个小引导，渐进培养表达素养。

### 机制（关键：每次接话 +1 小引导）
- 你接住兜底递的钩子（模块2）时，系统附带一个小引导：
  - "这次试试先说结论"
  - "下句用一个比喻"
  - "停一拍再接，更有分量"
- 这些小引导积累成你的"表达素养库"（素材/技巧/习惯）
- 不是练习 APP，是真实场景里每次接话长一点

### 输出
- 渐进式素养培养（每次接话 +1 个小技巧/素材）
- 素养库可视化（你积累的表达技巧）

### 实现
模块2触发后，阶跃星辰生成"接话小引导" + 素养库存储。
**72h**：✅ 高（小引导生成是 LLM 短输出，接话事件已有）。

## 四模块关系（一个真实场景里的闭环）

```
你真实讲话
  ├─ 模块1 实时评判效果（好不好）        -> 复盘
  ├─ 模块2 兜底递钩（卡壳救场）          -> 你接话
  │      └─ 模块4 接话时 +1 小引导       -> 素养培养（成长）
  └─ 模块3 跨会话积累能力 -> 铸证（可证）
```
- 模块1评、模块2兜、模块3证、模块4养 -- 评判/兜底/证明/培养四件事，在一个真实场景里同时发生。
- **既是辅助（模块2救场）也是成长（模块4培养）**，不是练习 APP。

## 手机 APP 版（现场参观者可用）

- 让现场参观者用手机体验：模块1（录一段，给表达效果评判）+ 模块4（接话小引导）
- 轻量版：不接眼镜/指环，用手机麦 + 云端评判
- 用途：让参观者也感受"被评判+被培养"，扩大体验面
