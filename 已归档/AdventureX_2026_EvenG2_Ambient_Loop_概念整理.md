# Even G2 Ambient Loop 助手：概念整理

> 载体：Even Realities G2 眼镜 + R1 指环
> 内核：垫话（在你需要时递一下）+ 2026 agentic loop（持续感知-自纠-进化）
> 调研日期：2026-07-22
> 配套：`AdventureX_2026_抗刷短视频_需求与实现方案.md`（前期调研）、`AdventureX_2025_项目特性校验与选题指南.md`

---

## 一、一句话定义

一个戴在脸上、持续运行的 ambient agent：它**不等你开口**，用"听到的话（讯飞 STT）+ 身体信号（R1 指环心率/压力）"实时判断你卡在哪，在 HUD 余光里递一个 discreet 的提示词，并把这个瞬间收进**你的个人模型**——**戴得越久越懂你**。

---

## 二、2026 概念定位（明确区别于 2025"主动式"）

| | 2025「主动式 Agent」 | 2026「Ambient Loop」(本项目) |
|---|---|---|
| 触发 | 一次性主动发起 | **持续运行**，ambient 常驻 |
| 交互 | 你要时它才在 | 你不召唤它也在感知，**活在余光** |
| 记忆 | 无/单次 | **跨会话个人模型**，越用越懂你 |
| wow | "它会主动干活" | **可见的进化**：你的"卡点图谱"在收紧 |
| 价值观 | 替你做 | **递一下，不替你**（垫不替） |

**热点缝合**：① agentic loop（感知-推理-行动-反思-进化）② ambient 环境智能（眼镜一直戴着）③ 个人记忆/个性化模型 ④ 多模态融合（音频+生理）⑤ glanceable AI（不抢注意力，活在余光）。这些不是堆砌，是同一条链的不同侧面。

## 三、核心：Agentic Loop 设计（可见的进化循环）

```
① 感知 Sense
   ├─ 手机麦克风 -> 讯飞 STT -> 对话文本流（"发生了什么"）
   └─ R1 指环 -> 被动 PPG/心率/压力（"你身体怎么反应"）
        ↓ 多模态融合
② 推理 Reason（Dify + 阶跃星辰）
   ├─ 对话状态：是否跑题/逻辑断裂/接不上
   └─ 生理状态：心率飙升=紧张、低唤醒=走神
        ↓ 判断"你此刻需要什么"
③ 行动 Act
   └─ HUD 余光递一个词/一个节点/一个节奏cue（不是整句，是"垫"）
        ↓
④ 反思 Reflect
   ├─ R1 点按=接住了（这个垫法有效）
   ├─ R1 双击=不需要（判断错了）
   └─ 对话是否恢复=结果信号
        ↓
⑤ 进化 Evolve
   └─ 更新你的个人模型：{情境×你的卡点类型×有效垫法}
        ↓ 可见收敛：卡点图谱随每次开口在收紧
```

**2026 loop 的赢点**：不是"递了一次话"，是**评委能看见"这个 agent 越来越懂这个佩戴者"**——某些情境的卡壳频率下降、有效垫法被记住。这是"持续进化循环"，不是 2025 的一次性主动。

---

## 四、硬件载体的独特优势（为什么是 Even G2 + R1）

这套组合有一个别家没有的**多模态融合**优势：

| 信号 | 来源 | 告诉 agent 什么 |
|------|------|----------------|
| 对话内容 | 手机麦 -> 讯飞 STT | "外部发生了什么"（你在说什么、接没接上） |
| 生理状态 | R1 指环被动 PPG | "你内部什么状态"（紧张/走神/卡壳，**你嘴上没说但身体在说**） |
| 余光提示 | G2 micro-LED HUD | 在旁人看不见处递一个词 |
| discreet 确认 | R1 四手势 | 旁人看不出你在操作 |

**关键差异点**：现有所有 AI 助手只看"你说什么"。本项目融合**"你说什么"+"你身体怎么反应"**——你嘴上镇定但心率飙升，agent 知道你其实在硬撑，该递一个接话茬了。这个融合是 R1 指环被动感知赋予的、别家眼镜没有的能力。

**G2 无摄像头反而是优势**：隐私友好、不引人注目、不会被对话对象察觉"你在录像"——这正是 ambient 助手要的"在场而不打扰"。

## 五、F1 场景（具体锚定）

> **为【在重要对话/汇报/答辩中容易卡壳的人】在【接不上话、说不到点上的瞬间】解决【没人替你递一下、自己又调不出状态】**

- 痛点真实：人人有过"脑子宕机、话到嘴边说不出"的时刻。
- 时刻明确：对话中卡壳的那几秒。
- 垫而不替：HUD 递一个接话茬/关键词，你自己组织语言说出来——你长了，不依赖。

## 六、F2 赞助商深用映射

| 赞助商 | 深用在哪 | 怎么用 |
|--------|---------|--------|
| **讯飞** | 语音感知层 | 手机麦 -> 讯飞实时 STT（对话流转写）+ 可选 TTS |
| **Dify** | loop + 记忆层 | 感知-推理-行动-反思工作流 + 跨会话个人模型存储 |
| **阶跃星辰** | 推理层 | 对话状态判断 + 生成"垫"的内容（节点级，非整句） |

三个赞助商深用，每层都说得清"用在哪"——这是 Whispr（去年靠 Dify+空间感知拿 2 奖）同款打法，搬到 Rokid/Even 这条更空的赛道。

---

## 七、现场 Demo 的 wow moment

1. 佩戴者现场讲一段汇报，**故意卡壳**
2. 大屏实时显示两路信号：对话文本流（讯飞 STT）+ 心率曲线（R1 指环）
3. 卡壳瞬间：心率飙红 + 对话断裂 -> HUD 余光递一个接话茬词
4. 佩戴者 R1 点按确认 -> 接住继续讲
5. 切到"个人模型"：这次卡点被记录，和上次对比，某情境频率下降
6. **可见的进化** = 全场看懂的 wow

## 八、与选题指南对齐与风险

| 特性 | 状态 | 说明 |
|------|------|------|
| F1 具体场景 | ✅ | "重要对话卡壳瞬间"是具体人具体时刻 |
| F2 技术深度 | ✅ | 讯飞 STT + Dify loop + 阶跃星辰 + 多模态融合(音频+生理)，是真技术活 |
| M1 现场演示 | ✅ | 眼镜可穿戴、HUD 可镜像、心率可可视化，60 秒可玩 |
| 赛道空白 | ✅ | Even Realities 是 2026 新赞助，去年仅 CatchVerse(Rokid)一个且未获奖，空白大 |
| 垫不替边界 | ⚠️ 须守 | HUD 递"节点"不递"整句"，否则退化成柚柚式嘴替 |

**核心风险**：① 垫话在手机上曾因"现场不能掏出来"被毙——眼镜解决了载体，但"戴 AR 眼镜进对话"的社会接受度仍是 demo 之外的现实问题（hackathon demo 可成立）。② R1 指环生理信号的稳定性/延迟需现场验证。③ 心镜(BCI 硬件)去年 0 奖的先例说明"硬件辅助注意力/状态"主题有难度——破局点全压在"loop 可见进化 + 多模态融合"的差异化上。

---

## 九、一句话总括

> **把"垫话"从手机（不实际）搬到眼镜（ambient 可行），用 2026 的 agentic loop 让它从"递一次话"升级成"持续学你、可见进化"，并用 R1 指环的被动生理信号做出"听懂你说的 + 感知你没说的"多模态融合——这是 Even G2 这套硬件独有、别家做不出的 ambient 助手。**
